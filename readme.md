# LocalGPT: A Fully Dockerized Local AI Assistant 🤖

LocalGPT is a locally hosted AI assistant that runs entirely using Docker containers. It uses **Ollama** to run Large Language Models (LLMs) locally and **Open WebUI** to provide a simple, ChatGPT-like web interface.

The application is managed using **Docker Compose**, allowing multiple containers to work together as a single application without depending on external AI APIs.
